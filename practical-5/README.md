Practical 5: R Control Structures, Functions, and Sequences
This repository contains R scripts for Practical 5, covering loops, conditional statements, user-defined functions, and sequence generation.  
R

Description of Contents
The provided R script includes the following examples and implementations:  
R

For Loops: Iterating through numerical sequences and vectors (e.g., printing squares of numbers, nested loops combining children and sweets).  
R

Conditional Control Flow: Using break and next statements within loops to control execution flow (e.g., stopping or skipping specific iterations based on conditions).  
R

While Loops: Executing code conditionally based on a logical test, including a custom function to calculate cumulative sums.  
R

Repeat Loops: Infinite loop structures managed with explicit break and next conditions.  
R

Custom Functions (function): Writing and executing user-defined functions with single arguments, multiple arguments, and internal loops.  
R

Sequence Generation (seq): Generating sequences with customized start points, endpoints, increments (by), and lengths.  
R

How to Run
Open your R environment or RStudio.

Load or source the lab5.R file.

Run individual blocks of code to observe the outputs for loops, functions, and sequence generation functions.
